# JavaScript Fundamentals 📜

A structured, sequential log of core JavaScript concepts — from environment setup through closures, the DOM, async patterns, and OOP — each topic in its own file for easy reference.

## Why This Repo Exists

Backend and frontend work both rest on solid JS fundamentals. This repo is a organized reference built while working through those fundamentals in depth, kept versioned rather than scattered across throwaway files.

## How to Use This

Each file is self-contained and runnable independently — open any file and run it with Node to see the concept in action:

```bash
node 36_LexicalScopingAndClosure.js
```

For browser-dependent topics (DOM, events), open the corresponding `.html` file directly.
